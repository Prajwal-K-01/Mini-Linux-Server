1. SERVER ADMINISTRATOR
-----------------------

Shell         : /bin/bash

- Sudo access

7. USER MANAGEMENT COMMANDS
---------------------------

Create administrator:
useradd -m -s /bin/bash serveradmin

Create developer:
useradd -m -s /bin/bash developer

Create backup user:
useradd -m -s /bin/bash backupuser

Add administrator to wheel:
usermod -aG wheel serveradmin

Add administrator to administrators:
usermod -aG administrators serveradmin

Add developer to developers:
usermod -aG developers developer

Add backup user to backup:
usermod -aG backup backupuser


8. VERIFICATION COMMANDS
------------------------

Check user:
id serveradmin

Check developer:
id developer

Check backup user:
id backupuser

Check groups:
getent group administrators
getent group developers
getent group backup

Check logged-in users:
who

Check user information:
getent passwd serveradmin
getent passwd developer
getent passwd backupuser
